# Resume-ATS-Calculator
📄 ATS Score Checker – Resume Matcher App

This is a simple Streamlit web app that helps users evaluate how well their CV matches a specific job role or job description using:

🔍 Keyword Matching for predefined roles across multiple industries
🤖 BERT-based Semantic Similarity for pasted job descriptions
📤 Upload your PDF Resume and instantly get a match score
🧠 Includes 20+ industries and hundreds of common roles
✏️ Allows manual job title entry if your role isn’t listed
🚀 Features
Upload resume in PDF format
Select role from an extensive industry-wise list
Optionally paste a job description for better matching
Instant ATS score with matched keywords highlighted
Friendly and intuitive UI using Streamlit
🛠️ Built With
Streamlit
PyPDF2
sentence-transformers (MiniLM)
Python 3.7+
